# Despliegue de Aplicaciones Web

# 🔧 Git y GitHub

Git y GitHub - Actividad documentada por Isabel Monica Martinez Lopez

## 🚀 Descripción de la actividad

En esta actividad he trabajado con Git y GitHub para practicar el control de versiones y el trabajo colaborativo entre diferentes desarrolladores.

Se han utilizado ramas, commits, Pull Requests y fusiones, además de trabajar con dos clones del repositorio para simular el trabajo de dos desarrolladores.

## 🛠️ Tecnologías y herramientas utilizadas

* Python
* Visual Studio Code
* Git
* GitHub

## 🔧 Proceso de desarrollo

El objetivo de la actividad es practicar el uso de Git y GitHub.

* Creación y configuración del repositorio.
* Creación de la rama `dev`.
* Trabajo con dos usuarios y dos clones del repositorio.
* Creación de ramas para desarrollar nuevas funcionalidades.
* Desarrollo y modificación de funciones en Python.
* Uso de `.gitignore`.
* Creación y resolución de un conflicto entre dos desarrolladores.
* Creación de Pull Requests.
* Fusión de ramas.
* Generación del historial del proyecto mediante `git log`.
* Creación del documento de entrega.

## 📄 Documentación

Se incluye el archivo `log.md` con el historial de commits realizado durante la actividad.

También se incluye `entrega.md` con el nombre y el enlace al repositorio de GitHub.

## 📂 Estructura del repositorio

* `main.py` → programa principal.
* `userfnc.py` → función para solicitar el nombre del usuario.
* `alert.py` → función encargada de mostrar la alerta de seguridad.
* `.gitignore` → archivos ignorados por Git.
* `log.md` → historial de commits.
* `entrega.md` → documento de entrega.
* `index.md` → documentación de la actividad.
